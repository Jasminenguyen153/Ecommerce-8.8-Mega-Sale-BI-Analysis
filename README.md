## Project Overview
This project demonstrates an end-to-end Business Intelligence workflow for analyzing the performance of an e-commerce 8.8 Mega Sale campaign.

The project includes:

- Database design using SQL Server
- Relational data modeling with primary and foreign keys
- SQL queries for business analysis
- Interactive Tableau dashboard
- Business insights and recommendations
## Development Notes
This project was independently designed and implemented using SQL Server and Tableau.
AI-assisted tools were used to support brainstorming, documentation, SQL optimization, and technical explanations. All database design decisions, business logic, validation, dashboard development, and final analysis were reviewed, tested, and verified by the author.
